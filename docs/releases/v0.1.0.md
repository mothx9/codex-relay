# Codex Relay v0.1.0

Your self-hosted Codex fleet, on iPhone. This release replaces the earlier RC
downloads with one versioned package set.

- Rebuilt with synchronization fixes: snapshot refresh runs independently of
  events/control; transient Codex sync errors keep the Hub socket and recover
  without repeated reconnections or stale pending requests.
- Faster native reconnection: live socket opens before optional HTTP bootstrap,
  bounded initial sync/pong deadlines, reusable HTTPS connections and redacted
  connection diagnostics on an affected device.
- Download-first installation: no repository clone or Go toolchain; guided
  one-time pairing and automatic platform/checksum selection.
- Native iPhone device IPA for signing/sideloading without Xcode. Free Apple
  accounts need a seven-day refresh. The embedded Home Screen PWA is the fastest
  route without a computer. No TestFlight/App Store link is provided yet.
- Compact Fleet: grouped active surfaces, green Working, distinct Needs You and
  Errors, and a quieter Recent list. A failed turn shows its exact cause in the
  conversation and accepts a new message to continue. Working scrolls with chat;
  the composer floats above it.
- Codex subagents show their role or nickname and parent session in Fleet and
  conversation detail, so parallel work is not presented as an unrelated thread.
- Pull down in Fleet to refresh machine/session discovery, or in a conversation
  to refresh its history, using the existing Hub connection.
- Connecting a read-only thread now explains an unavailable session or an
  existing Codex writer inline while keeping its history readable. Retry after
  the other writer releases the thread; Relay does not take over that writer.
- Smaller floating composer and centered glass jump-to-latest control that appears
  only when recent content is meaningfully out of view.
- Canonical queued Follow-ups and direct Steer, image picker/drop input,
  individually navigable activities, file diffs and partial-height live questions.
- Refreshed screenshots, recorded walkthrough and platform-neutral diagrams.

**Install:** [download guide](https://github.com/mothx9/codex-relay/blob/v0.1.0/docs/setup/downloads.md) ·
[iPhone guide](https://github.com/mothx9/codex-relay/blob/v0.1.0/docs/setup/iphone.md) · [walkthrough](https://github.com/mothx9/codex-relay/blob/v0.1.0/docs/assets/app/recordings/native-walkthrough.mp4).

**Compatibility:** Codex app-server 0.160.1; native iOS 17+; Linux amd64/arm64 and
macOS arm64 Agents. Hub installer targets Linux. Keep existing Hub state and
credentials when upgrading; no database reset or re-pairing is required.

**Notifications:** connected local alerts are included. Native remote APNs needs
an entitled Apple signing team and Hub provider key; physical remote delivery is
not claimed by this release. Home Screen Web Push is a separate free path.

`SHA256SUMS` and `release.json` identify the exact packages and source commit.
The unsigned IPA contains no personal provisioning profile or signing identity.
