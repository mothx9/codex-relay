# v0.1.0 release validation

Validation date: 2026-10-08. This records the downloadable self-hosted release
scope; native remote APNs and Apple consumer distribution remain separate.

## Automated and native checks

- Go formatting, vet and race tests; nine web control tests.
- Ten disposable installer tests, including the default versioned download,
  checksum rejection, stdin pairing and actual restart of an existing service.
- Two packaging tests: exact artifact isolation, repeatable executable archives,
  manifest/checksums, and rejection of simulator/mismatched/private-signing IPAs.
- Localization and repository-local documentation links.
- 69 Swift core tests without failures.
- Eight simulator behavioral cases: composer/menu/keyboard, canonical queued Steer,
  live question draft, offline typing, compact Fleet, direct file inspection,
  Working scrolling away while the composer remains available, and five-line
  drafts preserving text and clearance above the floating dock.
- Dedicated screenshot and recording tests using isolated production-view fixtures.
  All 23 public screens and the approximately 16-second MP4/GIF were regenerated
  after the final layout changes. Fleet fixtures include three Working sessions;
  public captures contain no real accounts, addresses, threads or credentials.

## Device and running services

The Release iPhone build was signed with the existing development team, installed
in place and launched successfully on the connected physical iPhone. No Keychain
reset or new enrollment was performed. This proves installation/launch, not owner
gesture acceptance or remote push delivery.

The reference Hub and all three Agents were upgraded to `0.1.0`, retaining service
definitions and credential hashes. The Hub database was backed up consistently
through SQLite's backup API. Shared Codex app-server process identities were
unchanged. Hub health returned `ok`; all Agents reported Online at `0.1.0`.

## Distribution boundaries

Host archives contain only the binary, installer, license and install guide.
The native package is a Release arm64 iPhoneOS build, marketing version `0.1.0`,
build `1`, minimum iOS `17.0`, without embedded personal provisioning or signing
material. Signing/sideloading remains necessary; an end-to-end AltStore install
is not claimed by the IPA structure/build checks.

The tag workflow builds a fresh package set from the tagged commit and prepares
a draft. Publication verifies the downloaded checksums and source manifest first;
old RC releases/tags are retired only after the replacement download works.
GitHub's repository Packages inventory reported zero entries; the superseded
downloads were GitHub Releases assets.

Native connected local alerts are supported. Physical remote APNs delivery,
TestFlight/App Store availability and the newest owner gesture acceptance are
not claimed. The [current status](../../status.md) remains the compatibility reference.
