# v0.1.0 refresh validation

Validation date: 2026-10-15. This refresh moves the v0.1.0 tag to a newer
source commit and replaces the release assets; it does not introduce a new
protocol or database version. Prior checksums and source hashes for v0.1.0
must not be reused.

## Changes in the refreshed source

- Native transcript live-follow uses the live-edge scroll policy while
  preserving a deliberate read position higher in the conversation.
- A local optional signing guard pins committed source and attempts to renew an
  Xcode-installed Personal Team app before its provisioning profile expires.
  It needs the paired physical iPhone and a usable Apple Account on that Mac.
- The native build number advances to 2 for an in-place iPhone update; its
  marketing version remains 0.1.0.

## Validation boundaries

Local qualification passed on 2026-10-15: Go formatting, vet and race tests;
nine web control tests; ten installer tests; two release-package tests;
localization and 204 repository-local documentation links; 79 Swift core tests;
and three signing-guard tests. Xcode built the signed native iPhone app with
marketing version 0.1.0 and build number 2. The app was installed over the
existing installation and launched on the paired physical iPhone without
erasing its data or enrollment.

The original [v0.1.0 validation](v0.1.0.md) records the earlier release and
reference Hub/Agent upgrade. A physical install/launch establishes that the
native binary opens; it does not prove physical streaming, notifications or all
owner gestures. The unsigned public IPA cannot renew its own free-account
profile. Native APNs and App Store/TestFlight distribution remain unaccepted.
