# Product assets

The native AppIcon uses the Codex symbol requested by the project owner. Its
source is the `codex_new` vector bundled in the official OpenAI Codex VS Code
extension, version 26.1002.51308. The vector geometry is preserved; an opaque
neutral background is added for iOS. `scripts/branding.py` renders it offline.

The Codex symbol and name belong to OpenAI; the repository Apache-2.0 license
does not grant rights to those marks. Codex Relay is an independent self-hosted
client and is not an official OpenAI application. Other Relay product assets
retain their existing identity.
